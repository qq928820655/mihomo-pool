轮换与门限

说明

7890 固定出口：在「节点」页点「设为固定」，重载后自动恢复。
7891 动态轮换：每 interval_s 秒在「关键词命中 + 延迟 ≤ max_ms」的节点里随机换一个。
7892 分配出口：调用 API 传入 key（如账号 ID），同一 key 稳定映射到同一节点。
17901+ 逐节点端口：每个节点一个独享端口，供 CPA/Hub 按端口绑定账号（自动发现前 10 个）。
自动测速：服务器后台每 auto_test_s 秒自动测全部节点并更新缓存，7891 轮换 / 7892 分配 / API 挑选都会自动避开超时节点。
后台独立性：轮换与自动测速都在服务器进程里跑，关闭网页完全不影响；API Token 只用于打开本面板，保存在浏览器本地，输入一次即可。
节点「超时」是服务器视角：部分机场入口（CDN 类）会拒绝机房 IP 的 TLS 握手（家里住宅 IP 正常），这类节点从服务器永远不通，属来源 IP 选择性，非配置问题。
端口可在 .env 用 MPOOL_HUB_PORTS=7890,7891,7892 自定义（改后重启服务生效）。
